설정된 주기의 정각에 맞춰 관측합니다. 서버 도착은 통신 상황에 따라 늦어질 수 있습니다.

관측과 에너지 기록 읽는 법
  • 통상 관측은 설정된 정각 주기로, 비상 상태는 60분 주기로 동작합니다. 실제 적용 주기는 위의 관측 메타데이터를 확인하세요.
  • 야간 기준은 태양 고도 −18°입니다. 야간 마감은 해당 시점 이후 첫 정규 관측이며 충전 종료를 직접 감지한 값이 아닙니다.
  • 실험 데이터는 일반 관측과 분리합니다. 실험 시 정규 관측 한 회가 생략될 수 있습니다.
  • 펌웨어·전력 정책·실험 승인과 결과는 관리자 화면에서 확인합니다. 공개 페이지에는 관리 정보와 실험 원시값을 노출하지 않습니다.
