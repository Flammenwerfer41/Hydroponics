    OPERATION

    관측 주기

    장치의 적용 상태를 확인하는 중입니다.

    1.1.0 이상에서 다음 통신 때 적용하고 장치에 저장합니다. 서버는 통상 주기를 제안하며 최종 주기는 장치가 결정합니다. 비상 상태는 60분 주기입니다. 3.3V 이하 또는 전압 측정 실패 시 진입하고, 서로 다른 기상 주기에 3.5V 이상을 두 번 확인하면 해제합니다.

    온라인 유지

    요청은 1시간 동안 유효합니다. 다음 기상 때부터 15분간 유지하며, 다시 요청하면 새 요청으로 연장됩니다.

    실험 초안과 결과

    실험 규격은 함께 설계하고, 여기서는 내용을 검토한 뒤 승인합니다. 초안 저장만으로는 장치에 전달되지 않습니다.

    실행 승인 전: 2.0 이상 설치 보고를 확인하세요. 활성 OTA 승인이 남아 있으면 설치 확인을 기다리거나 펌웨어 영역에서 수동 중지하세요. 유지보수 요청이 없어야 하며 최근 2시간 내 실험 대기 상태 보고가 필요합니다.

    시작 3.5V 이상 · 보호 평균 3.4V 미만 중단 · 최대 60초 계획 / 600표본. 이미 장치에 저장된 실험은 원격 취소가 즉시 적용되지 않습니다.

      승인된 실험 · 결과

      실험 결과

      배경은 실제 실행 단계입니다. 전압은 보드 ADC 기반이며 전류·소비전력·셀 휴지전압이 아닙니다. 결측값과 미수신 구간은 선을 연결하지 않습니다.

      실험 중 정규 관측 한 회가 생략될 수 있습니다. 실험 직후 못 보낸 결과는 이후 기상 때 나누어 전송됩니다. ‘결과 수집 완료’여도 실험 자체는 중단되었을 수 있으므로 종료 사유를 확인하세요.

      SIGNED OTA

      펌웨어 등록과 배포

      로컬에서 서명한 JSON과 동일한 앱 바이너리를 함께 선택하세요. 서버가 서명·해시·보드·버전을 검사합니다. 등록만으로는 배포되지 않습니다.

      승인된 버전의 장치 보고와 새 관측이 확인되면 설치 완료를 기록하고 해당 배포 승인만 자동으로 해제합니다. 등록 파일과 관리 이력은 남습니다.

      1.1.0 이상: 자동 OTA 3.6V 이상 / 명시적 수동 요청 3.5V 이상. 비상 상태에서는 모두 금지합니다. 이전 펌웨어는 수동 요청과 무관하게 기존 3.8V 제한을 유지합니다. 수동 요청은 선택한 승인 버전에만 1시간 유효하며 재시도 횟수를 초기화하지 않습니다. 중지는 이후 다운로드를 막으며 설치 중인 장치를 즉시 중단시키지 않습니다. 최대 3회 시도, 실패 후 1시간·6시간 대기. 복구 버전도 더 높은 번호로 빌드하세요.
